## XA-06 addendum: the MDBX binding

`libmdbx` 0.6.6 (MPL-2.0, pinned `=0.6.6` in the workspace manifest) is the one crate in the tree that
wraps a C library for storage. `mdbx-sys` 13.11.0 compiles the vendored libmdbx 0.13.11 C source
(`libmdbx/mdbx.c`, about 100,000 lines); the count above is 0 because the script reads `src/` and
`build.rs` only, not that C file, so the real exposure is the whole C library. The wrapper crate holds
the Rust `unsafe` (50 tokens); `xone-db` and every crate of ours keep `forbid(unsafe_code)` and call only
the safe API of `xone_db::mdbx`. `bindgen` 0.72.1, `clang-sys` and `libloading` are build-time
dependencies of `mdbx-sys` (they need libclang when it builds); they run in the build, not in the node.
`parking_lot` 0.12.5 comes in through `libmdbx`. `reth-libmdbx` is not published on crates.io, which is
why this crate was chosen. Owner review is pending, as for every row.
