## Status words

- applies: the defect class can occur in xOne. A defence exists or is required.
- applies by design: the xOne design removes the defect class. A test must prove that.
- not applicable: the class cannot occur. The row gives the source reason.
- GAP in the last column: no test proves the defence. The machine list is `audit-gaps.txt`.
- Corpus tests: `every_negative_vector_is_rejected_with_its_error` runs each file in `conformance/vectors/consensus/negative/`. The file name in the row is the proof for that row.
